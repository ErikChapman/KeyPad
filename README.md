## ✨ О проекте

**KeyPad** — проект компактного дополнительного клавиатурного блока / макропада. Репозиторий предназначен для разработки аппаратной части устройства, включая электрическую схему, печатную плату, прошивку и 3D-модель корпуса.

Проект основан на беспроводной логике управления и предназначен для дальнейшей разработки и экспериментальной сборки.

Проект находится на стадии разработки. Концепт устройства и электрическая схема могут отражать разные этапы проектирования и не являются гарантией окончательной конфигурации устройства.

## 🛠️ Как открыть проект

1. Установите **Altium Designer**.
2. Откройте файл `KeyPad.PrjPcb`.
3. Для работы с основной схемой используйте `MainLogic.SchDoc`.
4. Для просмотра электрической документации откройте `MainLogic.pdf`.

## 🔧 Разработка

Проект можно использовать как основу для дальнейшей проработки аппаратной части, подготовки PCB, разработки прошивки и создания корпуса.

Перед изготовлением рекомендуется выполнить полную проверку схемы, цепей питания, радиочастотной части, посадочных мест компонентов и соответствия выбранных компонентов требованиям проекта.

## ⚠️ Важные замечания

- Прошивка и исходный код программного обеспечения в репозитории не представлены.
- Наличие отдельных инженерных файлов не означает подтверждённую готовность к производству.
- Финальный BOM, электрические параметры и совместимость компонентов необходимо проверять непосредственно перед изготовлением.
- Концепт, схема и будущая механическая конструкция могут изменяться независимо друг от друга.
- Перед изготовлением рекомендуется дополнительно проверить электрическую схему и все инженерные документы.

## ✨ About the project

**KeyPad** is a compact additional keyboard block / macropad project. The repository is intended for developing the hardware part of the device, including the electrical schematic, PCB, firmware and 3D model.

The project is based on wireless control logic and is intended for further development and experimental assembly.

The project is currently under development. The device concept and electrical schematic may represent different design stages and do not guarantee the final configuration of the device.

4. Open `MainLogic.pdf` to view the electrical documentation.

## 🔧 Development

The project can be used as a foundation for further hardware development, PCB preparation, firmware development and enclosure design.

Before manufacturing, it is recommended to perform a complete review of the schematic, power circuits, radio-frequency section, component footprints and compliance of the selected components with the project requirements.

## ⚠️ Important notes

- Firmware and software source code are not included in the repository.
- The presence of individual engineering files does not mean that the project is confirmed to be production-ready.
- The final BOM, electrical parameters and component compatibility must be checked directly before manufacturing.
- The concept, schematic and future mechanical design may change independently of one another.
- Additional verification of the electrical schematic and all engineering documentation is recommended before manufacturing.
