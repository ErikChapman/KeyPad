## ✨ О проекте

**KeyPad** — проект компактного дополнительного клавиатурного блока / макропада. Репозиторий предназначен для разработки и документирования аппаратной части устройства: электрической схемы, компонентов, библиотек и сопутствующих инженерных материалов.

Проект находится на стадии разработки. Концепт устройства и электрическая схема могут отражать разные этапы проектирования, поэтому окончательные характеристики и состав изделия необходимо проверять по исходным инженерным файлам.

## 🚦 Статус проекта

| Раздел | Статус |
|:--|:--|
| 🧩 **Схема** | Основной файл схемы и PDF-экспорт присутствуют в репозитории |
| 🟩 **Печатная плата** | Проектная структура и материалы PCB присутствуют; финальная плата не подтверждена |
| 💾 **Прошивка** | В репозитории пока не представлена |

## 🛠️ Как открыть проект

1. Установите **Altium Designer**.
2. Откройте файл `KeyPad.PrjPcb`.
3. Для работы с основной схемой используйте `MainLogic.SchDoc`.
4. Для просмотра электрической документации откройте `MainLogic.pdf`.

## 🔧 Разработка

Проект можно использовать как основу для дальнейшей проработки аппаратной части, подготовки PCB, разработки прошивки и создания корпуса.

Перед изготовлением рекомендуется выполнить полную проверку схемы, цепей питания, радиочастотной части, посадочных мест и механических ограничений.

## ⚠️ Важные замечания

- Прошивка и исходный код программного обеспечения в репозитории не представлены.
- Наличие проектных материалов печатной платы не означает подтверждённую готовность к производству.
- Финальный BOM, электрические параметры и совместимость компонентов необходимо проверять непосредственно в Altium Designer.
- Концепт, схема и будущая механическая конструкция могут изменяться независимо друг от друга.
