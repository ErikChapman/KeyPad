## О проекте

**KeyPad** — проект компактного дополнительного клавиатурного блока / макропада. Репозиторий предназначен для разработки и документирования аппаратной части устройства: электрической схемы, компонентов, библиотек и сопутствующих инженерных материалов.

Проект находится на стадии разработки. Концепт устройства и электрическая схема могут отражать разные этапы проектирования, поэтому окончательные характеристики и состав изделия необходимо проверять по исходным инженерным файлам.

## Статус проекта

| Раздел | Статус |
|:--|:--|
| **Схема** | В репозитории присутствует основной файл схемы и PDF-экспорт |
| **Печатная плата** | Проектная структура и материалы PCB присутствуют; финальная плата не подтверждена |
| **Прошивка** | В репозитории не представлена |
| **3D-модель** | Присутствуют 3D-модели отдельных компонентов; финальная модель устройства не представлена |

## Как открыть проект

1. Установите **Altium Designer**.
2. Откройте файл `KeyPad.PrjPcb`.
3. Для работы с основной схемой используйте `MainLogic.SchDoc`.
4. Для просмотра готовой документации откройте `KeyPad.pdf` или `MainLogic.pdf`.

## Основные материалы

- `KeyPad.PrjPcb` — основной файл проекта Altium Designer.
- `MainLogic.SchDoc` — главный документ электрической схемы.
- `KeyPad.pdf` — PDF-документация проекта.
- `MainLogic.pdf` — PDF-экспорт основной схемы.
- `CC1101RGPR/` — библиотечные материалы компонента CC1101RGPR.
- `ESP32-H2FH4/` — библиотечные материалы компонента ESP32-H2FH4.
- `keyswitches.pretty-2.1/` — библиотека footprints клавишных переключателей.
- `keyswitches.pretty-2.1-alt/` — альтернативные библиотечные материалы клавишных компонентов.

## Ограничения

- Прошивка и исходный код программного обеспечения в репозитории не представлены.
- Наличие проектных материалов печатной платы не означает подтверждённую готовность к производству.
- Финальный BOM, электрические параметры и совместимость компонентов необходимо проверять непосредственно в Altium Designer.
- Концепт, схема и будущая механическая конструкция могут изменяться независимо друг от друга.

## Разработка

Проект можно использовать как основу для дальнейшей проработки аппаратной части, подготовки PCB, разработки прошивки и создания корпуса. Перед изготовлением рекомендуется выполнить полную проверку схемы, цепей питания, радиочастотной части, посадочных мест и механических ограничений.
